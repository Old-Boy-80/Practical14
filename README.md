# Text Analyzer GUI Application
The program takes input from the user and give line count, space count, tab count, length, etc based on the analysis.

## Features:
- **Line count:** Gives total line count of users input text.
- **Space count:** Gives total space count.
- **Tab count:** Gives total tab count.
- **Unique Character count:** Gives count of characters.
- **User Specified Word count** Gives count of user specified word.
